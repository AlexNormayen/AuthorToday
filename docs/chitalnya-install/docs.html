Читальня — документация

Неофициальный iOS-клиент Author.Today

«Читальня» не является официальным приложением Author.Today и не связана с порталом. Author.Today не отвечает за работу этого клиента. Книги и оплата контента — только на author.today.

Что умеет приложение

  • вход в аккаунт Author.Today (email/пароль, при необходимости — код подтверждения устройства);
  • библиотека, поиск, лента, карточка книги, читалка;
  • кэш открытых глав и скачивание книг для офлайна;
  • локальные оповещения об обновлениях на устройстве;
  • импорт своих TXT/EPUB только на устройство;
  • виджет «Продолжить чтение».

Расширенная конфигурация клиента

Помимо базового чтения доступна расширенная конфигурация: дополнительные темы оформления, снятие лимита на скачивание книг целиком, закладки и заметки в читалке, режим «перелистывание», свои цвет и фон читалки, расширенный импорт TXT/EPUB.

В приложении из App Store / TestFlight расширенная конфигурация привязана к вашему аккаунту Author.Today и подтягивается после входа. Книги и оплата контента портала здесь не продаются.

Отдельная оплата удобств клиента (вне App Store) описана на странице поддержки; для пользователей App Store достаточно этой документации и поста на Author.Today.
