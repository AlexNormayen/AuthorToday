Установка приложений

IPA для iPhone / iPad. Ставятся через SideStore на устройстве или Sideloadly на ПК. Apple Developer не нужен.

Установка через SideStore

  1. Один раз установите SideStore по их инструкции (нужен ПК).
  2. На iPhone/iPad откройте эту страницу в Safari и скачайте нужный IPA ниже.
  3. В SideStore: + → выберите скачанный IPA → Install.
  4. Доверьте сертификат: Настройки → Основные → VPN и управление устройством.
  5. Раз в ~7 дней делайте Refresh в SideStore — иначе приложение перестанет открываться (бесплатный Apple ID).

Через Sideloadly (ПК)

  1. Скачайте IPA на компьютер.
  2. Откройте в Sideloadly, подключите устройство по USB, укажите Apple ID.

Файлы не подписаны Apple. Подпись делает SideStore / Sideloadly вашим Apple ID.
