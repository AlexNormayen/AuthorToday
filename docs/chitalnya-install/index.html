Файл не подписан Apple. SideStore подпишет его вашим Apple ID на устройстве (~7 дней на бесплатном аккаунте).

Установка через SideStore

  1. Установите SideStore (по их инструкции, с ПК один раз).
  2. На iPhone/iPad откройте эту страницу в Safari и скачайте AuthorToday.ipa.
  3. В SideStore: + → выберите скачанный IPA → Install.
  4. Доверьте сертификат разработчика: Настройки → Основные → VPN и управление устройством.
  5. Раз в ~7 дней обновляйте подпись в SideStore (Refresh), иначе приложение перестанет открываться.

Через Sideloadly (ПК)

  1. Скачайте IPA на компьютер.
  2. Откройте в Sideloadly, подключите устройство по USB, укажите Apple ID.
