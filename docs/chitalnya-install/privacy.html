Политика конфиденциальности

Приложение «Читальня» · обновлено: 9 сентября 2026

Публичный URL для App Store Connect: https://tv.theinquisitor.ru/chitalnya/privacy.html

«Читальня» — клиент Author.Today (неофициальный), независимый iOS-клиент для чтения с портала author.today. Приложение не является официальным продуктом Author.Today, не связано с порталом; Author.Today не отвечает за работу этого клиента.

Какие данные обрабатываются

  • Учётные данные Author.Today. Email/логин и пароль (и при необходимости код подтверждения) отправляются напрямую на API Author.Today (api.author.today). Мы не ведём собственный сервер аккаунтов и не храним пароль на своих серверах.
  • Токен сессии. Токен авторизации и ключ устройства хранятся локально в Keychain на вашем iPhone.
  • Настройки и прогресс чтения. Тема, шрифты, офлайн-кэш глав и прогресс хранятся локально (UserDefaults, файлы в Documents, SwiftData).
  • Свои файлы («Мои книги»). Импортированные TXT/EPUB копируются только на устройство (Application Support) и не отправляются на Author.Today. На сервер разработчика они попадают только если вы явно включите «Облачную полку» (см. ниже).
  • Фото. Доступ к фотобиблиотеке используется только если вы сами выбираете картинку как фон читалки. Фото не загружается на наши серверы.
  • Уведомления. Локальные оповещения формируются на устройстве по данным API Author.Today. Отдельный сбор push-токена на наш сервер не выполняется.

Опциональная облачная полка (сервер разработчика)

В настройках можно добровольно включить синхронизацию «Облачная полка». В сборках из App Store функция выключена по умолчанию и требует явного включения.

При включении на сервер разработчика Читальни (tv.theinquisitor.ru, HTTPS) могут передаваться:

  • идентификатор пользователя Author.Today (числовой user id);
  • скачанные главы / метаданные книг для бэкапа;
  • прогресс чтения и закладки;
  • импортированные локальные TXT/EPUB, если вы их синхронизируете.

Доступ к API защищён токеном, который вы вводите сами (в App Store-сборке токен не зашит в приложение). Отключение полки прекращает новые загрузки; уже сохранённые копии на сервере можно запросить удалить через контакт ниже.

Передача третьим лицам

Сетевые запросы уходят на сервисы Author.Today (API и сайт для оплаты книг) и, только при включённой облачной полке, на сервер разработчика Читальни. Разработчик «Читальни» не продаёт персональные данные пользователей и не передаёт их рекламным сетям. Рекламного и кросс-приложенческого трекинга нет.

Покупки

Оплата книг и сервисов Author.Today выполняется на официальном сайте author.today. Приложение не обходит оплату и не подменяет платёжный процесс портала.

Дополнительно в приложении доступна подписка и разовые покупки «Читальня Pro» через систему покупок Apple (In‑App Purchase / StoreKit). Pro открывает удобства самого клиента (темы оформления, расширенный офлайн, режимы читалки, импорт своих TXT/EPUB на устройство) и не является оплатой книг Author.Today, не даёт скидок на контент портала и не связано с Author.Today. Обработку платежей и чеков выполняет Apple; разработчик «Читальни» не получает данные вашей карты.

Удаление данных

Удаление приложения с устройства удаляет локальный кэш, настройки, токены и импортированные файлы из «Мои книги». Аккаунт Author.Today управляется на сайте author.today. Данные на облачной полке (если включали) удаляются по запросу на контакт ниже.
